A desktop Git client that
shows your history as a graph

GitDenn is a free, fast Git GUI. See every branch and merge at a glance, stage and commit with a click, and keep stashes, cherry-picks and merges close at hand.

Download GitDenn

Windows and macOS. All downloads are on the releases page.

What it does

Everything you reach for every day, without the command line.

Interactive commit graph

Branches and merges drawn on a canvas, with the default branch always on the left in the theme green. Click any commit for its message and files.

Side-by-side diffs

See the whole file split old and new, jump between changes, use the mini map, and turn word wrap on or off.

Stage and commit

Stage files or whole folders, then write a commit message or generate one locally from your changes.

Branches that make sense

A tree grouped by /, ahead/behind counts, stale-branch dimming, and a marker showing which local branches are on origin. Double-click to check out.

Stashes, done well

Stash everything, or just one file or folder. Each stash shows in the graph as its own commit, with a green Pop button and Apply and Drop beside it.

Merge, cherry-pick, squash

Right-click for merge, cherry-pick and squash. If something conflicts, GitDenn cancels cleanly and leaves your repo untouched.

Safe pull and push

Pull and rebase auto-stash your local changes first. Push goes straight through; the force option appears only if the remote rejected it.

List or tree file views

View changed files as a flat list or a folder tree, with collapsible folders, and copy a file's name or path from the right-click menu.

Open it anywhere

Open the repo in GitHub, VS Code (Ctrl+Shift+E), your file manager or a terminal. It reopens your last repo on start-up.

Installing

GitDenn isn't code-signed yet, so your system may ask you to confirm the first run.

WindowsRun the installer. If SmartScreen appears, choose More info → Run anyway. A portable .exe is also provided.
macOSOpen the .dmg and drag GitDenn to Applications. On first launch, right-click → Open. Use arm64 for Apple silicon, x64 for Intel.
RequiresGit installed and on your PATH.

Open source

MIT licensed. Built with Electron and plain JavaScript — no framework and no build step.

git clone https://github.com/morgdenn/gitdenn.git
cd gitdenn
npm install
npm start

Source, issues and contributing notes are on GitHub.
